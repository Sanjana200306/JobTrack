# JobTrack
A job application tracking system built using Java, Spring Boot and MySQL.


# JobTrack - Job Application Tracker

## About
JobTrack is a project designed to help users
organize and track their job applications.

## Technologies Used
- Java
- Spring Boot
- MySQL
- Maven
- Git and GitHub

## Features
- Track job application status
- Store application details in MySQL
- Manage application records through REST APIs

## Project Structure
- controller: Handles API requests
- model: Defines application data
- repository: Handles database operations

## Setup Instructions
1. Clone this repository.
2. Configure your MySQL database.
3. Update database settings in application.properties.
4. Run the application using Maven.

## How to Run
Windows:
mvnw.cmd spring-boot:run
